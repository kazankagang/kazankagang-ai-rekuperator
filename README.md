# AI-Рекуператор

Демо для хакатона FinTech Academy: банк сам находит в операциях клиента случаи, когда положен возврат денег, и готовит претензию.

## Что внутри

- **Главная** — промо-страница продукта.
- **Клиент** — загрузка выписки (CSV) или демо-выписка, поиск случаев по правилам (задержки рейсов, подписки, двойные списания, страховки по кредитам, период охлаждения), расчёт суммы и претензия.
- **Банк** — дашборд пилота: возвраты, комиссия, рейтинг мерчантов (демо-данные).

Один файл `index.html`, без сборки и зависимостей: скачайте репозиторий и откройте `index.html` в браузере.

## Формат CSV

```
дата;описание;сумма;категория;детали
2026-10-01;Авиакомпания, билет Москва — Сочи;8400;Авиабилеты;рейс NW1234, 12.10.2026, задержка 4.3 ч
```

Сумма списания положительная, поступления отрицательная.

## Ограничения прототипа

- Генерация претензии и «Доп. проверка ИИ» работают через Claude, когда страница открыта как Artifact в Claude. В обычном браузере претензия собирается по шаблону.
- Шанс успеха — экспертные веса по типу случая, не ML-модель.
- Данные дашборда и выписки демонстрационные.
