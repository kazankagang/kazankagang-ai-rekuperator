# AI-Рекуператор

Демо для хакатона FinTech Academy. Банк сам находит в операциях клиента случаи, когда ему положен возврат денег, считает сумму и готовит претензию.

## Что внутри

- **Главная**: промо-страница продукта.
- **Клиент**: загрузка выписки (CSV) или демо-выписка, поиск случаев по правилам, расчёт суммы, претензия и согласие на отправку.
- **Банк**: дашборд пилота с возвратами, комиссией и рейтингом мерчантов (демо-данные).

Правила находят пять сценариев:

| Сценарий | Основание |
|---|---|
| Задержка рейса: штраф, страховка к карте, еда в аэропорту | ВК РФ ст. 120, ФАП-82 п. 99 |
| Пробный период стал платной подпиской | ЗоЗПП ст. 32 |
| Двойное списание | ГК РФ ст. 1102 |
| Страховка по досрочно погашенному кредиту | 353-ФЗ ст. 11 ч. 10, 12 |
| Отказ от страховки в период охлаждения | Указание ЦБ № 3854-У |

## Запуск

Нужен Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r backend/requirements.txt
uvicorn backend.app.main:app --reload
```

Откройте http://localhost:8000

Чтобы претензии писал ИИ, перед запуском задайте ключ Claude API:

```bash
export ANTHROPIC_API_KEY=sk-ant-...
```

Без ключа всё работает, только претензия собирается по шаблону, а кнопка «Доп. проверка ИИ» выключена. Модель можно сменить переменной `REKUPERATOR_MODEL` (по умолчанию `claude-opus-5-5`).

### В VS Code

1. Откройте папку проекта: File → Open Folder.
2. Поставьте расширение Python, VS Code сам предложит его из рекомендаций.
3. Выберите интерпретатор (Ctrl+Shift+P → «Python: Select Interpreter»), лучше созданный `.venv`.
4. Установите зависимости: Ctrl+Shift+P → «Tasks: Run Task» → «Установить зависимости».
5. Нажмите F5 и выберите «AI-Рекуператор: сервер». Сайт откроется в браузере сам.

Ключ Claude API можно положить в файл `.env` (образец в `.env.example`).

Через Docker:

```bash
docker build -t rekuperator .
docker run -p 8000:8000 -e ANTHROPIC_API_KEY=sk-ant-... rekuperator
```

## API

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/health` | статус и включён ли ИИ |
| GET | `/api/demo` | демо-выписка и найденные случаи |
| POST | `/api/analyze` | загрузка CSV (`file`), возвращает операции и случаи |
| POST | `/api/claim` | текст претензии по случаю |
| POST | `/api/ai-scan` | дополнительные случаи от ИИ |
| GET | `/api/dashboard` | данные дашборда банка |

Документация Swagger: http://localhost:8000/docs

## Формат CSV

```
дата;описание;сумма;категория;детали
2026-10-01;Авиакомпания, билет Москва — Сочи;8400;Авиабилеты;рейс NW1234, 12.10.2026, задержка 4.3 ч
```

Сумма списания положительная, поступления отрицательная. Разделитель `;` или `,`, дата `ГГГГ-ММ-ДД` или `ДД.ММ.ГГГГ`.

## Ограничения прототипа

- Шанс успеха задан экспертными весами по типу случая. В MVP его заменит модель, обученная на исходах дел пилота.
- Данные дашборда и демо-выписки вымышлены.
- Отправка претензии пока только отмечается в интерфейсе.
