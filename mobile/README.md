# Рекуператор для Android

Android-приложение для клиента. Это обёртка [Capacitor](https://capacitorjs.com) над тем же фронтендом, что и веб-демо (`frontend/`): тот же пастельный дизайн, экраны «Главная», «Клиент» и «Банк».

## Как поставить на телефон

1. Откройте на телефоне страницу релиза **android-latest** в репозитории: `Releases` → «Рекуператор для Android (свежая сборка)».
2. Скачайте `rekuperator.apk`.
3. Откройте файл. Android попросит разрешить установку из этого источника (браузера или «Файлов»): разрешите и нажмите «Установить».

Если релиза ещё нет или он не открывается, APK лежит в артефакте сборки: вкладка `Actions` → последний запуск «Android APK» → `rekuperator-apk` (скачается zip, внутри APK). Его можно перекинуть на телефон через USB, Telegram «Избранное» или облако.

Каждая сборка подписана своим отладочным ключом. Если новая версия не ставится поверх старой («Приложение не установлено»), удалите старую и поставьте заново.

## Режимы работы

**Офлайн (по умолчанию).** Сервер не нужен. Демо-выписка и дашборд банка встроены в приложение, а свою CSV-выписку разбирает прямо на телефоне `frontend/js/offline.js`: те же правила, что на бэкенде, претензии собираются по шаблону. Пример выписки со всеми пятью сценариями: `backend/tests/data/statement_all_cases.csv`.

**С сервером.** Чтобы претензии писал ИИ и работала «Доп. проверка ИИ»:

1. Запустите бэкенд так, чтобы он был виден в локальной сети:
   ```bash
   uvicorn backend.app.main:app --host 0.0.0.0 --port 8000
   ```
2. Узнайте IP компьютера (Windows: `ipconfig`, строка «IPv4-адрес», например `192.168.1.10`). Телефон и компьютер должны быть в одной Wi-Fi сети. Если не подключается, разрешите Python в брандмауэре Windows.
3. В приложении на экране «Клиент» нажмите «Сервер» и введите `http://192.168.1.10:8000`.

Пустой адрес возвращает офлайн-режим.

## Сборка

APK собирает GitHub Actions (`.github/workflows/android.yml`) на каждый пуш, который меняет фронтенд, бэкенд или `mobile/`. Запустить вручную: `Actions` → «Android APK» → `Run workflow`.

Локально нужны Python 3.10+, Node 22, JDK 21 и Android Studio:

```bash
pip install -r backend/requirements.txt
cd mobile
npm ci
npm run build                          # frontend/ -> www/ и data/offline.json
npx cap add android                    # один раз
npx capacitor-assets generate --android
npx cap sync android
npx cap open android                   # Android Studio: Run или Build > Build APK
```

`www/` и `android/` генерируются и в git не хранятся. Иконка и заставка лежат в `assets/`, рисует их `scripts/icons.js`.
